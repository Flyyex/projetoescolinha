# TRUCKAUTO - 

Aplicação Full-Stack em Node.js com interface mobile-first PWA, sistema de autenticação JWT, cálculo automatizado de rendimentos de frotas e centro de comando administrativo.

## Como Rodar Localmente:
```bash
npm install
npm start
```
Acesse: `http://localhost:3000`

## Como Fazer Deploy no Render:
1. Suba este repositório para o GitHub.
2. No Render.com, clique em **New +** ➔ **Web Service**.
3. Selecione o repositório.
4. Build Command: `npm install`
5. Start Command: `node server.js`
6. Pronto! O Render gerará seu link público HTTPS.
